## Overview

### lib/i18n

Provides a robust, signal-based internationalization (i18n) system for Angular 20+, supporting dynamic locale switching, translation pipes, localStorage persistence, and extensible locale management for multilingual enterprise applications.

### lib/theme

Implements a centralized, runtime theme management framework using CSS variables and design tokens, enabling dynamic theme switching, scoped component theming, and seamless integration with Angular 20 standalone components for consistent branding and multi-tenant
